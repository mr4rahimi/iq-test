# آزمون هوش (IQ Test)

نسخه تحت وب آزمون هوش چندبخشی با **Next.js 16**، **React 19**، **TypeScript** و **Tailwind CSS 4** (راست‌به‌چپ و فارسی).

## روش‌های آزمون

| روش | توضیح |
| --- | --- |
| 🎯 جامع | ۳۰ سؤال (۵ سؤال از هر بخش با سختی ۱ تا ۵)، ۳۰ دقیقه |
| ⚡ سریع | ۱۲ سؤال (۲ سؤال از هر بخش)، ۱۰ دقیقه |
| 📈 تطبیقی (CAT) | ۱۸ سؤال؛ سختی سؤال بعدی بر اساس پاسخ قبلی بالا یا پایین می‌رود |
| 🏋️ تمرین بخشی | ۱۰ سؤال از یک بخش، بدون محدودیت زمان و با نمایش پاسخ و توضیح |

## بخش‌ها

- 🔢 **هوش عددی** — دنباله اعداد و مسائل محاسباتی (بانک سؤال)
- 📖 **هوش کلامی** — تشابه، مترادف، متضاد، ناهمخوان (بانک سؤال)
- 🧩 **استدلال منطقی** — قیاس، استنتاج، معما (بانک سؤال)
- 🔷 **ماتریس‌های تصویری** — به سبک ریون، تولید تصادفی با قواعد سطر/ستون/مربع لاتین
- 🧊 **تجسم فضایی** — چرخش ذهنی و تصویر آینه‌ای چندضلعی‌های تصادفی
- 🧠 **حافظه کاری** — فراخوانی رشته اعداد (مستقیم و معکوس) و فهرست واژه‌ها

## امتیازدهی

نمره با **مدل راش (IRT یک‌پارامتری)** و برآورد MAP محاسبه می‌شود و به مقیاس IQ (میانگین ۱۰۰، انحراف معیار ۱۵) تبدیل می‌شود. به همین دلیل در آزمون تطبیقی هم که سؤال‌ها سختی متفاوتی دارند نمره قابل مقایسه است. نتایج در `localStorage` مرورگر ذخیره می‌شوند.

> این آزمون جنبه آموزشی و سرگرمی دارد و جایگزین آزمون‌های استاندارد بالینی نیست.

## اجرا

```bash
npm install
npm run dev
```

سپس <http://localhost:3000> را باز کنید.

## ساختار

```
app/                 صفحات (خانه و /test/[mode])
components/          اجرای آزمون، نمایش نتیجه، اشکال SVG، منحنی نرمال
lib/banks/           بانک سؤال‌های عددی، کلامی و منطقی
lib/generators/      مولدهای ماتریس، فضایی و حافظه
lib/scoring.ts       مدل راش و تبدیل به IQ
lib/plan.ts          ساخت آزمون برای هر روش
```

برای افزودن سؤال، کافی است یک آیتم به فایل بانک مربوطه اضافه کنید (گزینه اول همیشه پاسخ درست است؛ ترتیب گزینه‌ها هنگام اجرا به‌هم می‌ریزد).
